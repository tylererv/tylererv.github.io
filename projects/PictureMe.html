PictureMe

An event photo delivery platform that uses face recognition to match attendees with the photos in which they appear.

🥇1st Place Winner at HornetHacks 2026
GitHub RepositoryLive Application
01

Project Description

Attendees register their face once, join an event through a QR code, and receive a personal gallery as organizers and contributors upload photos. The application also supports event roles, invitations, contributor access, a complete event gallery, and scoped gallery-sharing links.

The current backend coordinates AWS Rekognition collections for face indexing and matching, Cloudinary for media storage, and Supabase for authentication and application data. The project documentation identifies SMS delivery and pgvector similarity workflows as future expansion areas.

02

Tech Stack

  • Frontend: React, TypeScript, and Vite.
  • Backend: Python and FastAPI.
  • Data and authentication: Supabase PostgreSQL.
  • Integrations: AWS Rekognition and Cloudinary.
03

Backend Pipeline and Access Model

The FastAPI backend separates account enrollment, event management, photo ingestion, face matching, and gallery delivery into dedicated services. Supabase bearer tokens identify the current user, while privileged database and media operations remain server-side.

  • Each event has creator, administrator, and member permissions for invitations, contributor access, photo management, and event settings.
  • The browser can request signed Cloudinary upload parameters, upload media directly, and submit the resulting references for asynchronous indexing.
  • AWS Rekognition collections isolate face indexes by event; matching results connect detected faces to registered profiles and personalized gallery records.
  • Separate endpoints return the complete event gallery and the authenticated user's matched photos, while scoped share tokens support controlled gallery links.
  • Supabase migrations define face profiles, events, upload jobs, matching data, gallery tokens, and database access policies; backend tests cover services, API contracts, authentication, matching, uploads, and cleanup behavior.
