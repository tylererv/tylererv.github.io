PictureMe

An event photo delivery platform that uses face recognition to match attendees with the photos in which they appear.

GitHub RepositoryLive Application
01

Project Description

Attendees register their face once, join an event through a QR code, and receive a personal gallery as organizers and contributors upload photos. The platform also supports event roles, a full event gallery, history, and SMS notifications when matching photos are ready.

The backend coordinates AWS Rekognition for face matching, Cloudinary for media storage, Twilio for SMS delivery, and Supabase with pgvector for application data and similarity search.

02

Tech Stack

  • Frontend: React, TypeScript, and Vite.
  • Backend: Python and FastAPI.
  • Data: Supabase PostgreSQL with pgvector.
  • Integrations: AWS Rekognition, Cloudinary, and Twilio SMS.
