Gone-Phishin

Gone-Phishin is a Chrome extension that adds a Gmail scanning workflow for checking whether an email appears to be phishing.

1

Project Description

The extension adds a "Scan this Email" action inside Gmail and sends the selected email content to a local Flask service. The backend uses the Google Gemini API to classify suspicious email content and help users identify phishing attempts before interacting with unsafe messages.

The repository also documents setup steps for installing dependencies, configuring the Gemini API key, running the local detector service, and loading the extension into Chrome developer mode.

2

Tech Stack

  • Chrome extension frontend with JavaScript
  • Python phishing detector service
  • Flask local server
  • Google Gemini API for AI-assisted email analysis
