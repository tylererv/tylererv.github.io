yt-dlpCommandBuilder

A Chrome side-panel extension that turns the current YouTube or SoundCloud URL into a customizable terminal command.

GitHub Repository
01

Project Description

The extension opens beside the active tab and builds yt-dlp commands for YouTube and SoundCloud. Users can edit separate templates for each platform, choose a YouTube output path, set a clip range, and control whether YouTube playlists are included.

Templates and preferences are saved locally in Chrome extension storage. The generated command can be copied to the clipboard and run in a terminal with separately installed yt-dlp and FFmpeg tools.

02

Tech Stack

  • Interface: HTML, CSS, and JavaScript.
  • Extension platform: Chrome Manifest V3 with a background service worker.
  • Browser integration: Side Panel, Tabs, local Storage, and Clipboard APIs.
03

Implementation Highlights

  • Tracks active-tab and URL changes so the side panel updates as the user navigates.
  • Detects supported platforms and switches between separately saved YouTube and SoundCloud templates.
  • Substitutes URL, path, clip-range, and playlist placeholders, appending enabled options when their placeholders are absent.
  • Disables command copying on unsupported pages and provides feedback when clipboard copying fails.
04

Architecture and Command Safety

A Manifest V3 service worker configures the side panel to open from the extension action, while the panel itself owns URL detection, settings, and command rendering. Hostname checks use the browser's URL parser so only YouTube, youtu.be, and SoundCloud domains enable command copying.

The generator quotes active URLs before inserting them into shell templates, cleans empty continuation lines, and appends enabled range or playlist flags when an older custom template does not contain the related placeholder. The extension never executes shell commands or downloads media inside Chrome; users review and run the generated command in their own terminal.
