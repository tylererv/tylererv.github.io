Osiris

An adaptive coding-practice platform that identifies skill gaps, builds personalized learning roadmaps, and guides users without simply giving away solutions.

GitHub Repository
01

Project Description

Osiris begins with an assessment, records performance and time data, and uses the results to recommend a sequence of coding problems. The application is designed around guided practice: its AI assistant gives Socratic hints that help a learner reason through a problem instead of returning a complete answer.

The architecture separates a Next.js interface, FastAPI REST API, Supabase authentication and PostgreSQL data, and a locally hosted Ollama model. Keeping inference local supports privacy while output validation helps the application keep the assistant within its intended coaching role.

02

Tech Stack

  • Frontend: Next.js and TypeScript.
  • Backend: FastAPI REST API.
  • Data and authentication: Supabase and PostgreSQL.
  • AI guidance: local Ollama inference with a gpt-oss model.
