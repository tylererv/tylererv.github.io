PrintGuard

PrintGuard is an AI-powered process monitoring platform for detecting 3D printing failures in real time across multiple cameras and printers.

1

Project Description

The platform monitors live webcam feeds, runs computer vision detection against each print, and surfaces a print health score for every active camera. When the model identifies a failure such as spaghetti, warping, stringing, or detachment, the system can notify users and send direct G-code commands to the affected printer over USB serial.

PrintGuard combines a Next.js frontend, FastAPI backend, Supabase database/auth layer, and YOLOv8 model pipeline to support individual makers, teams, labs, and print farms.

2

Tech Stack

  • Frontend: Next.js and TypeScript
  • Backend: FastAPI, OpenCV, and pyserial
  • Database and authentication: Supabase PostgreSQL with Row Level Security
  • Computer vision: YOLOv8 with Ultralytics and PyTorch
