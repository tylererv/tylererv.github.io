# Getting Started

This portfolio is a static GitHub Pages site. There is no framework build step and no package installation required for normal editing.

## Preview

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Editing Pages

- Edit `index.html` for the home/about page.
- Edit `projects.html` for the project index.
- Edit `research.html` for the research index.
- Edit `work-experience.html` for role focus and experience content.
- Edit files in `projects/` for individual project case pages.
- Edit files in `research/` for individual research detail pages.

## Styling

Edit `styles.css` first. The page theme uses dark green, grey, and black through CSS custom properties at the top of the file.

The served stylesheet is `styles.min.css`. Keep it in sync with `styles.css`.

## JavaScript

Edit `script.js` first. It controls:

- mobile navigation
- scroll reveal
- gentle parallax
- external project-card link handling

The served script is `script.min.js`. Keep it in sync with `script.js`.

## Deployment

GitHub Pages serves the repository root. Push changes to the configured Pages branch to deploy.
